HRMIS HOUSING REGISTRY MODULE UPDATE

IMPORTANT: Extract this ZIP directly into your existing HRMIS project root:
C:\Users\USER\Documents\CODEBASE\virtenv\HRMIS
Allow files to merge/overwrite when prompted. This update does NOT include or replace your existing migrations, .env file, config settings, or database.

1. Back up your existing HRMIS folder first.
2. Extract this ZIP into the HRMIS project root.
3. Open PowerShell and activate the same virtual environment used for HRMIS.
4. Change to the project directory:
   cd C:\Users\USER\Documents\CODEBASE\virtenv\HRMIS
5. Install/update dependencies:
   python -m pip install -r requirements.txt
6. Generate a new migration for the added optional house information fields:
   python manage.py makemigrations housing
7. Apply it:
   python manage.py migrate
8. Run checks:
   python manage.py check
9. Start the server:
   python manage.py runserver

FIRST-TIME LOCATION SETUP
Before registering/importing houses, sign in as a Django superuser and open /admin/.
Create the Island records (Pohnpei, Chuuk, Yap, Kosrae), then their official Municipality records, then Village records. Use the official IOM project location names. This module deliberately does not guess or auto-create municipalities/villages from spreadsheet text.

ENGINEER SETUP
Create Django user accounts and EngineerProfile records in /admin/. Each engineer needs a unique Employee ID. Optional engineer assignment during Excel import uses this Employee ID.

HOUSE ID CONVENTION
Suggested examples: HR-PNI-0001, HR-CHK-0001, HR-YAP-0001, HR-KSA-0001. Confirm the final convention with the project team before bulk registration. House IDs are unique and should remain permanent.

EXCEL IMPORT
Use the in-app Download Excel template button. Required columns are house_id, island, municipality, village, latitude, longitude. Optional fields may be left blank. Import is all-or-nothing: if any row has an error, no records are created. Location names must match the records in HRMIS.

PERMISSIONS
The housing web registry permits superusers to create, edit, delete and bulk import houses. Non-superusers only see houses currently assigned to their EngineerProfile. Housing master data is not editable by engineers; their updates belong in reconstruction progress/photo workflows.

NOTE
The Excel import requires openpyxl. The requirement has been added to requirements.txt.
